# 実機（iPhone）で試す

iPhone の **Expo Go** というアプリの中で、このアプリを動かす。
Apple の開発者登録やビルドは要らない。Mac で開発用のサーバー（Metro）を動かし、iPhone がそこからアプリを読み込む。

## 用意するもの

- iPhone に **Expo Go**（App Store で「Expo Go」を検索して入れる。入っていれば最新に更新しておく）
- iPhone と Mac を **同じ Wi-Fi** につなぐ（iPhone は VPN を切る）。
  外から試すときは、Wi-Fi の代わりに Tailscale でつなぐ（下の「外のネットワークから（Tailscale）」）

## 開き方

1. Mac で、このフォルダ（login-demo）でサーバーを起動する

   ```bash
   npm run device
   ```

   ターミナルに QR コードと `exp://10.32.1.36:8081` のようなアドレスが出る（数字は Mac の IP アドレス）。

2. iPhone の **カメラ** で QR コードを読み、出てきた「Expo Go で開く」を押す
   - QR が読めないときは、Expo Go を開き「Enter URL manually」に上のアドレスを入れる
   - 初めてのとき「ローカルネットワーク上のデバイスの検索と接続」を聞かれたら **許可** する

3. 1〜2分ほど読み込んで、ログイン画面が出たら準備完了

一度開いたあとは、Expo Go のホームの一覧（MyApp）から開き直せる。サーバー（手順1）は動かしたままにしておく。

## つながらないとき

| 起きること | 直し方 |
| --- | --- |
| 「Could not connect to the server」・ずっと読み込み中 | iPhone と Mac が同じ Wi-Fi か、VPN が切れているかを確かめる |
| 同じ Wi-Fi なのにつながらない | 会社の Wi-Fi は、端末どうしの通信を止めていることがある。下の「外のネットワークから（Tailscale）」を使う |
| 「You need to be signed in to Expo Go and Expo CLI to open your project.」 | LAN の外（Tailscale・トンネル）から開いている。「外のネットワークから（Tailscale）」のサインインをするか、Mac と同じ Wi-Fi から開く |
| 「Project is incompatible with this version of Expo Go」 | App Store で Expo Go を最新にする（このアプリは Expo SDK 58） |
| Mac の IP が変わった（別の Wi-Fi にした など） | サーバーを止めて（Ctrl + C）、`npm run device` をやり直し、新しい QR を読む |
| 直したはずの見た目が変わらない（Mac のシミュレーターと違う） | iPhone のアプリが古いまま。画面に浮いている歯車のボタン（Expo Go のメニュー）→「Reload」で読み直す（ログインし直しになる）。マイアプリに戻って開き直すだけでは、アプリそのものは新しくならない |

### 外のネットワークから（Tailscale）

iPhone と Mac が同じ Tailscale のネットワーク（tailnet）に入っていれば、Wi-Fi が別でも、モバイル回線でも開ける。
インターネットには公開されない（tailnet の中の端末だけが届く）ので、下のトンネルより安全。

**Expo のアカウントでのサインインが要る。** Expo Go は、ふつうの LAN（10.x・172.16〜31.x・192.168.x）以外のアドレスから開くとき、
署名された内容しか開かない。Tailscale の 100.x もこれに当たる（サインインしていないと
「You need to be signed in to Expo Go and Expo CLI to open your project.」と出る）。最初に1回だけ:

- Expo のアカウントを作る（無料。expo.dev）
- Mac で `npx expo login`（Mac のブラウザが開くので、そこでサインイン）
- このプロジェクトを Expo に登録する: `npx eas-cli@latest init`（app.json に `extra.eas.projectId` が入る。**このプロジェクトは登録済み**）
- iPhone の Expo Go で、同じアカウントにサインインする（Expo Go の「Profile」）

そのうえで:

1. Mac で

   ```bash
   npm run device:tailscale
   ```

   ターミナルに `exp://100.x.x.x:8081`（Mac の Tailscale のアドレス）と、その QR コードが出る。
2. iPhone で Tailscale をつないだ状態（VPN がオン）にする
3. QR コードを読むか、Expo Go の「Enter URL manually」に上のアドレスを入れる

`npm run device`（Wi-Fi 用）と同時には動かせない。使うほうだけ起動する。

### 外のネットワークから（トンネル）

```bash
npm run device:tunnel
```

Expo のトンネル（ngrok）を通すので、iPhone がモバイル回線でも開ける。
トンネルのアドレスも LAN の外なので、Tailscale と同じく Expo のアカウントでのサインインが要る。
ただし、開発用のサーバーが（推測しにくいアドレスで）インターネットから届くようになる。中身はアプリのプログラムで、パスワードなどは入っていないが、使い終わったら止めること。

## 確かめること

保存・申請のボタンは、本当にデータが書き込まれる。試すときは、自分のデータで、あとで直せる範囲で。

- [ ] ログインできる（「ユーザー名を保持する」を入れると、次から名前が入っている）
- [ ] マイアプリに、Web と同じアプリが並ぶ。下に引っぱると読み直す
- [ ] ライト / ダーク: iPhone の設定（画面表示と明るさ）を切り替えると、アプリも切り替わる
- [ ] 見た目（iOS 26 の Liquid Glass）: 灰色の地に白いカード。ログインのボタンはガラス。EZCraft の画面の下のボタン（登録など）は、浮いたガラスのカプセル
- [ ] 近道「勤務表」で、メニューを飛ばして勤務表が開く。戻るとマイアプリに戻る
- [ ] マイアプリを開いて数秒たってから近道を押すと、すぐに行き先が開く（裏でメニューを読んで準備しておくため。準備中に押すと、近道のアイコンがくるくる回り、準備ができしだい開く）
- [ ] 勤務表: 上に「今日と未登録の日」、その下にほかの日が日付の順に並ぶ
- [ ] 日を押すと、その日の「勤怠実績登録」が開く（勤怠日がその日になっている）
- [ ] 勤怠実績登録: 時刻を入れて **登録** できる。戻ると勤務表に反映されている
- [ ] 勤怠実績登録を、登録せずに戻ると、勤務表は読み直さずにすぐ出る（登録・削除したときだけ読み直す）
- [ ] 勤務表の下のガラスのタブ（勤務表・集計・申請状況・出力・工数）で切り替えられる。開くと自分の分がすぐに出る。‹ › で月を変えられる
- [ ] 勤怠実績登録: 一般・平日で 9:00〜18:00（休憩 1 時間）を入れると、「残業 0:30（17:30〜18:00）」のカードが出る。9:00〜17:30 なら出ない
- [ ] 残業のカードの「残業申請を作る」で、残業申請がシートで開き、日付・開始・終了が入っている（理由を入れて登録するだけ）。× か下に引っぱると元の画面に戻る
- [ ] 残業のある日を **登録** すると、登録のあと残業申請のシートが自動で開く。申請したあと、その日は「作成済み」と出る
- [ ] どの画面も、開いたときに整う前の見た目（白い地・パソコン向けの並び）が見えず、くるくる回る印のあとに整った画面が出る
- [ ] 入力欄を押したとき、画面が勝手に拡大しない。キーボードで入力欄が隠れない
- [ ] 給与・住民税・健診・資格取得者検索・Walk the Talk が開ける
- [ ] 勤怠申請の「承認待ち・申請検索・休暇照会」は、開くと自分の分がカードで出る（申請検索の条件は「検索の条件」を押すと開く）
- [ ] 勤怠実績登録: 「削除」は画面のいちばん下に小さく出る。「ほかの日をコピー」は時刻の欄の下のカードにある
- [ ] プロジェクト選択: 一度選んだプロジェクトが、次から上の「最近」に出る（押すとその番号で探す）
- [ ] 給与・賞与明細: 明細を押してパスワードを入れると、明細の PDF がアプリの画面で開く。左上の ‹ で明細の一覧に戻れる。右上の共有のボタン →「“ファイル”に保存」で保存できる（名前は「給与明細_支給日」など）
- [ ] どの画面も、横にスワイプしても動かない（何もない所が出ない）。上下の端で引っぱっても、外の地が見えない
- [ ] 勤怠実績登録: 番号の欄を押すと「今月のプロジェクト」が下から出て、選ぶと番号とプロジェクト名が入る。「番号を入力する」でキーボードから打てる（勤務表を開いたときに、今月の工数を裏で読んでおく）
- [ ] 勤務表: 「残業をまとめて申請（◯日）」で日を選ぶシートが出る。外したい日は押してチェックを外す。「◯日分を申請する」で、残業申請が1日ずつ（1/◯、2/◯…）日付・開始・終了・前回の理由が入った状態で開く。登録すると次の日が開く。× で閉じると残りはやめる
- [ ] 2回目以降に同じ画面を開くと、前より早く出る（画面の定義をアプリが覚えている）
- [ ] しばらく使わずにいたあと、「ログインが切れました」が出てログイン画面に戻る
- [ ] EZCraft のお知らせ（「健診予約が登録されていません。」など）は、画面の下のほうに白い小さな知らせで出て、数秒で消える。ダイアログの題名や × を隠さない
- [ ] 健康診断: 1年より前のお知らせは出ない。受診登録の注意書きが途中で切れない
- [ ] 勤怠のメニュー: お知らせのカードに、空の白い余白が残らない。メニューのカードを押すと、次の画面が出るまでカードの右にくるくるが出る
- [ ] 勤務表の集計・申請状況・出力・工数: 健康管理時間の帯は出ない。「CSV出力」は、検索の条件を開かなくても押せる。出力で、勤務のない日は「勤務の記録なし」と出る
- [ ] 勤怠実績登録: 長いプロジェクト名は欄の中で2行に折り返して全部見える。テレワークの四角が文字と同じ高さにある
- [ ] 一覧のページ送り（« < 1 / 15p > »）が、真ん中に並んだ押しやすい丸いボタンになっている
- [ ] 残業をまとめて申請のシートが画面の下の端までつき、後ろの一覧がのぞかない。行を横にずらしても押したことにならない（シートが閉じるだけで、画面ごと戻らない）
- [ ] 給与・賞与明細: 年の欄が「2026年 ▾」のように1つの欄に見える
- [ ] 年月・日付を選ぶ部品（勤務表のカレンダーの印、有給休暇申請の休暇取得日、ほかの日をコピー など）が、画面の下から出るシートになる。暗い所を押すと閉じ、後ろの行は押されない。選んだあと、選択の印やキーボードが出ない
- [ ] 有給休暇申請: 付与数・使用数・残数が「27日 6時間」のように出る。付与・ステータスの切り替えに飾りの印がない
- [ ] 健診の予約・受診: 必須の印（＊）が欄の見出しの後ろに出る（欄の印や画面の端と重ならない）。日付の欄の文字が左寄せ。選択肢の組に四角い枠がない
- [ ] 住民税: 「2026年度分」が1つの見出しに見える。資格取得者の検索: 取得年度の2つの欄が同じ幅
- [ ] Walk the Talk: 歩数のカードの「歩」が数字のすぐ後ろにある
- [ ] ダークモードでも、上のどれも文字が読め、色がおかしくない
- [ ] ダイアログやシートが開いているあいだ、上のヘッダーもいっしょに暗くなる。シートには上のつまみと ✕ があり、後ろの一覧が透けない
- [ ] 給与明細の一覧・資格取得者の検索・選ぶダイアログの一覧が、指でなぞると勢いよく流れ、最後まで見られる
- [ ] 申請検索: カードの題名が「2026/11/09・岡崎 昂功・有休」、状況が色の札（承認済は緑）、承認は1人1行で日付が右
- [ ] 休暇照会: どのカードにも「有休・付与数」のような見出しがある。チェックボックスが2列にそろう。「合計 ----」が出ない
- [ ] 入力欄の 🔍 やカレンダーの印の前に、縦の線が出ない

気づいたことは、画面のスクリーンショット（サイドボタン + 音量を上げる）と一緒に伝える。

## いまの制限

- Mac でサーバーが動いていて、iPhone から届くあいだだけ使える
- Expo Go を閉じると、ログインし直しになる（ログインの情報を保存していないため）
- 右側に出る歯車のボタンは Expo Go の開発用メニュー（このアプリのものではない）
- Mac につながずに使える形（TestFlight など）にするには、Apple Developer Program と Expo（EAS）のアカウントで、アプリをビルドして配る必要がある
